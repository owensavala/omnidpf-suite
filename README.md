# ⚡ OmniPDF Offline - 28 Alat PDF Lengkap (iLovePDF Complete Suite)

Aplikasi suite PDF serba bisa yang dirancang menyerupai layanan web **iLovePDF secara lengkap**, namun **100% berjalan offline** di komputer Anda tanpa memerlukan koneksi internet, tanpa batasan ukuran file, dan menjaga kerahasiaan dokumen Anda secara penuh.

---

## 🌟 Daftar 28 Alat PDF Lengkap

### 📂 1. Organisir PDF
1. **🖼️ Gambar ke PDF (JPG to PDF):** Gabungkan banyak foto (JPG, PNG, WEBP, BMP) menjadi 1 PDF berurutan. Geser posisi foto naik/turun sesuka hati.
2. **📑 Gabungkan PDF (Merge PDF):** Menyatukan 2 atau lebih file PDF menjadi 1 dokumen tunggal.
3. **✂️ Pisahkan PDF (Split PDF):** Ekstrak rentang halaman tertentu (misal: `1-3, 5`) atau pecah seluruh halaman menjadi file terpisah (ZIP).
4. **🔀 Urutkan Halaman (Organize PDF):** Atur ulang urutan halaman PDF sesuai nomor urut yang diinginkan (misal: `3, 1, 2, 4`).
5. **🔄 Putar PDF (Rotate PDF):** Putar orientasi dokumen 90°, 180°, atau 270°.
6. **🗑️ Hapus Halaman (Remove Pages):** Buang halaman yang tidak diperlukan dari PDF Anda.

### 🗜️ 2. Optimasi & Edit Dokumen
7. **🗜️ Kompres PDF (Compress PDF):** Perkecil ukuran dokumen (Pilihan: Ekstrem, Rekomendasi, atau Ringan).
8. **⬛ Sensor PDF (Redact PDF):** Sensor dan hapus permanen data sensitif (NIK, Nomor Telepon, Nama) dengan kotak sensor hitam.
9. **📐 Potong Halaman (Crop PDF):** Pangkas margin putih berlebih pada seluruh halaman PDF.
10. **✏️ Edit / Tambah Teks (Edit PDF):** Bubuhkan teks baru, keterangan, catatan, atau tanggal pada halaman PDF.
11. **💧 Tambah Watermark:** Sematkan teks cap air diagonal/horizontal seperti *'RAHASIA'*, *'DRAFT'* dengan transparansi fleksibel.
12. **🔢 Nomor Halaman:** Bubuhi penomoran otomatis di posisi bawah tengah, bawah kanan, atau atas tengah.
13. **🛠️ Perbaiki PDF (Repair PDF):** Pulihkan file PDF yang korup atau rusak menggunakan rekonstruksi tabel xref MuPDF.

### 🔄 3. Konversi ke PDF
14. **Gambar ke PDF** (JPG, PNG, WEBP, BMP, TIFF)
15. **Word ke PDF** (.docx $\rightarrow$ .pdf dengan akurasi 100% Office)
16. **PowerPoint ke PDF** (.pptx $\rightarrow$ .pdf slide beresolusi tajam)
17. **Excel ke PDF** (.xlsx $\rightarrow$ .pdf tabel landscape rapi)
18. **HTML ke PDF** (.html $\rightarrow$ .pdf dokumen standar A4)
19. **Teks ke PDF** (.txt, .md $\rightarrow$ .pdf)

### 🔁 4. Konversi dari PDF
20. **PDF ke Gambar** (PDF $\rightarrow$ PNG / JPG / WEBP beresolusi tinggi dalam format ZIP)
21. **Ekstrak Gambar Asli** (Ekstrak seluruh foto asli beresolusi penuh yang tertanam di PDF ke ZIP)
22. **PDF ke Word** (PDF $\rightarrow$ .docx yang dapat diedit langsung)
23. **PDF ke Excel** (PDF $\rightarrow$ .xlsx dengan deteksi tabel otomatis)
24. **PDF ke PowerPoint** (PDF $\rightarrow$ .pptx dengan tiap halaman menjadi slide presentasi)
25. **PDF ke PDF/A** (Konversi ke standar arsip internasional ISO PDF/A-1b)
26. **PDF ke Teks** (PDF $\rightarrow$ .txt)

### 🔒 5. Keamanan & Tanda Tangan
27. **✍️ Tanda Tangan PDF (Sign PDF):** Gambar tanda tangan langsung menggunakan kanvas mouse/touchpad atau unggah tanda tangan pada halaman dan posisi yang ditentukan.
28. **🔒 Kunci PDF (Protect PDF):** Enkripsi dokumen menggunakan sandi kuat berstandar AES-256.
29. **🔓 Buka Kunci PDF (Unlock PDF):** Hilangkan password dokumen yang terkunci agar bisa dibuka bebas tanpa kata sandi.
30. **🔍 Bandingkan 2 PDF (Compare PDF):** Bandingkan dua dokumen PDF dan dapatkan laporan perubahan isi teks antar versi.

## 🚀 Cara Menjalankan

### Cara 1: Web Interface Lengkap (Persis iLovePDF) — Rekomendasi
Cukup klik ganda (double-click) pada file:
👉 **`Buka_iLovePDF_Offline.bat`**

Browser Anda akan langsung terbuka secara otomatis ke alamat:
`http://localhost:5000`

Tampilannya bersih, elegan, bergaya kartu interaktif lengkap dengan fitur **Drag & Drop**, kanvas tanda tangan langsung, pencarian alat, pengurutan file, dan tombol unduh langsung.

---

### Cara 2: Desktop GUI Klasik (Tkinter)
Jika Anda ingin jendela aplikasi desktop tanpa lewat browser:
👉 Klik ganda file **`Jalankan_Converter.bat`**
